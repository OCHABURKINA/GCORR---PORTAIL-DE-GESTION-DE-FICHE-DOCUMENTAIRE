Chargement du portail…

Centraliser, publier et consulter les fiches d’intervention de la Réponse Rapide

Ce portail permet aux organisations membres du GCORR de publier leurs fiches d’intervention au format PDF en les associant à une organisation, une Alerte ID et une commune d’intervention.

Les fiches publiées peuvent être recherchées, consultées et téléchargées afin d’améliorer la coordination, la traçabilité des interventions et le partage de l’information opérationnelle.

Publication simplifiée

Publiez une fiche d’intervention en quelques étapes.

  1. Sélectionner l’organisation
  2. Sélectionner l’Alerte ID
  3. Sélectionner la commune concernée
  4. Ajouter le fichier PDF
  5. Confirmer la publication

Référentiel

Ajouter ou modifier une Alerte ID

Une Alerte ID peut être enregistrée avec plusieurs communes. Utilisez une ligne par commune dans le fichier CSV.

Importation

Importer les Alertes ID

Le fichier CSV doit contenir les trois colonnes suivantes :

alerte_id,region,commune
778_260625_KOUOUA,Nakambé,Ouargaye
777_260615_SANPIB,Koulsé,"Pibaoré; Korsimoro; Ziga"
Une alerte peut couvrir plusieurs communes

Répétez la même Alerte ID sur plusieurs lignes lorsqu’elle couvre plusieurs communes. Les doublons exacts seront ignorés pendant l’importation.
